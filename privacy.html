2. What Data the App Processes

Shape Unfold is designed to process a minimum of personal data:

  • Subscription verification: The App communicates with the Microsoft Store / a licensing server to verify whether the User has an active, valid subscription. This involves transmitting a license/account identifier assigned by the Microsoft Store — the Provider does not have access to payment details (card numbers, etc.), which are processed exclusively by Microsoft
  • Project geometry data (dimensions, shapes, calculations) that the User creates within the App remains stored locally on the User's device and is not sent to the Provider's servers unless the User actively uses a sharing/export feature
  • Diagnostic and crash data: The Microsoft Store platform may automatically collect basic diagnostic information (such as crash reports, device type, OS version, and app usage statistics) at the platform level to help identify and fix technical issues. This is governed by Microsoft's own privacy policy; the Provider does not operate a separate analytics or tracking SDK within the App

The App does not include any advertising or third-party analytics/tracking SDKs beyond the license verification and platform-level diagnostics described above.
